# 架构补充说明

这个目录补充的是与 `智能安防知识问答平台.txt` 对齐、但不强制要求本地跑通的工程模块。

## 已补充的模块

### 1. 文档解析链路

- `app/ingestion/parsers.py`
  - `PyMuPDFParserAdapter`
  - `UnstructuredHiResLoaderAdapter`
  - `TesseractOCRAdapter`

### 2. 切分链路

- `app/ingestion/chunk_pipeline.py`
  - `ChapterSemanticChunkPipeline`

### 3. 嵌入链路

- `app/embeddings/bge_encoder.py`
  - 私有化部署 `bge-large-zh-v1.5` 的封装蓝图
- `app/embeddings/sparse_encoder.py`
  - BM25 + DAAT 稀疏检索蓝图

### 4. 向量库链路

- `app/vectorstore/milvus_schema.py`
  - Dense / Sparse 双索引 schema 与参数说明
- `app/vectorstore/milvus_cluster.py`
  - Milvus 集群蓝图
- `deploy/docker-compose.milvus.yml`
  - Docker 部署示例

### 5. 工作流链路

- `app/graph/state.py`
- `app/graph/nodes.py`
- `app/graph/builder.py`

这些模块明确体现了 LangGraph 风格的节点、边和人工审核中断设计。

### 6. 评估链路

- `app/evaluation/corrective_rag.py`
- `app/evaluation/adaptive_rag.py`
- `app/evaluation/ragas_loop.py`

分别对应：

- 检索侧纠偏
- 回答侧自适应评估
- RAGAS 闭环指标

## 说明

当前项目保留了一个可直接运行的轻量主链路，同时新增了与 txt 对齐的完整架构模块。这样你在面试中既可以展示真实可跑的接口，也可以展示面向生产化演进的模块拆分能力。
