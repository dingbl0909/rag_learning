# 告警处置与误报治理

## 布控告警排查思路

布控告警出现异常时，应先判断是规则命中异常、算法阈值不合理，还是数据上送链路有重复。排查顺序建议为：核对布控规则范围，检查摄像头场景是否发生变化，查看算法版本与阈值配置，最后结合事件时间线确认是否存在重复上送。

## 高频误报治理

当系统频繁产生误报时，优先检查图片质量、目标遮挡、夜间补光、算法阈值和黑白名单配置。不要只调整单个阈值，而应同时比对样本质量与场景变化，否则容易造成误报下降但漏报上升。

## 告警联动建议

若布控告警需要触发短信、弹窗或工单联动，建议先在测试环境验证命中规则，再在生产环境逐步放量。对影响范围较大的规则变更，应保留审批记录，并设置人工复核节点，避免因误配置导致批量误报。

## 关闭告警的风险提示

关闭告警、批量修改规则或调整联动策略都属于高风险操作。系统应先展示触发原因、影响范围和最近命中记录，再由人工确认是否继续执行。
