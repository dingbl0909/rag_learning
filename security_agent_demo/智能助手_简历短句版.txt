项目名称：安防场景私有化大模型平台与多Agent智能助手

项目简介：
在依图负责安防场景私有化大模型平台落地，面向运维人员和前场实操人员，建设统一的智能问答与流程辅助平台。

核心内容：
1. 基于 LangChain + LangGraph 搭建多Agent协同框架，采用主Agent + 设备运维Agent + 告警处置Agent + 知识问答Agent + 现场作业Agent 的架构，支持复杂任务拆解与动态路由。
2. 围绕安防业务将流程拆分为视频流和图片流两类场景，分别支持监控告警分析、录像回溯、抓拍研判、图片问答和现场作业辅助。
3. 将设备管理、告警中心、知识库、工单系统、图像分析平台等后端能力抽象为标准化工具，支持大模型按需调用。
4. 引入 RAG 检索增强机制，结合内部知识库、作业手册和处置规范，提升专业问答与流程指引的准确性。
5. 设计用户身份注入、权限校验、敏感操作中断确认、Memory 持久化和状态栈管理机制，保障多轮对话下的上下文一致性与高风险操作可控。
6. 形成可私有化部署的大模型平台底座，支持模型替换、Agent扩展、工具接入和业务场景复用。

项目亮点：
1. 从传统FAQ升级为“问答理解 + Agent编排 + 工具执行”的闭环智能助手。
2. 支持视频流/图片流双场景分流处理，更贴合安防真实业务。
3. 支持私有化部署，满足企业对数据安全、权限隔离和审计追踪的要求。

简历表述版：
在依图负责安防场景私有化大模型平台落地，基于 LangChain + LangGraph 设计多Agent协同工作流，支持设备运维、告警处置、知识问答和现场作业辅助。围绕视频流与图片流两类业务场景，完成 RAG 增强、工具调用、权限风控和状态管理能力建设，为运维人员和前场实操人员提供智能问答、故障定位和流程辅助能力。

面试表述版：
我在依图做的是一个面向安防场景的私有化大模型平台，核心是把大模型从单纯问答升级成可落地的业务助手。整体上我用 LangChain + LangGraph 搭了一个主Agent加多个子Agent的协同框架，让模型能够根据用户问题动态路由到设备运维、告警处置、知识问答和现场作业等不同流程。同时结合视频流和图片流两类安防场景，分别对接监控告警、录像检索、抓拍分析和知识库系统，再通过 RAG、工具调用、权限控制和状态管理把整套能力串起来，最终服务运维人员和一线实操人员。

模型建议：
1. 商业化版本建议使用 70B 级别私有化指令模型，如 Qwen2-72B-Instruct，用于复杂推理、多工具调用和企业级平台部署。
2. 实战版本建议使用 7B~8B 级别模型，如 Qwen2-7B-Instruct，适合快速完成 RAG 问答、标准流程问答和轻量Agent调用。
