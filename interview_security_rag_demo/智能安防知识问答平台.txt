项目背景：

    针对安防场景中视频处理、人脸识别、设备接入、布控告警、项目部署及故障排查等知识分散在算法文档、交付资料、部署手册、接口说明和历史案例中的问题，传统关键词检索难以满足复杂问题定位需求，且通用大模型在垂直场景下存在知识滞后和幻觉率高的问题。为提升研发、实施和运维团队的问题定位效率与知识获取准确性，构建基于大模型的 RAG 知识问答系统，实现安防领域知识的实时更新、混合检索和可验证回答。

项目实现：
1. 基于弹性分布式部署的 Milvus 集群构建向量数据库服务，采用 Docker 方式部署，支持节点横向扩展与海量文档向量存储。
2. 使用 PyMuPDF 解析 PDF/PPT 等项目资料，并通过私有化部署的 UnstructuredLoader 加载 PDF、Word、HTML 等非结构化文档，结合 hi_res 策略提取章节层级、表格和版面结构；针对截图、扫描件等内容使用 Tesseract OCR 提取图片文本信息。
3. 设计“章节段落分块 + SemanticChunker 语义分块”混合切分方案，减少技术手册、接口说明和跨页表格在切分过程中的语义断裂问题。
4. 基于私有化部署的 bge-large-zh-v1.5 生成 Chunk 稠密向量，并结合 BM25 构建关键词稀疏检索能力，在 Milvus 中建立 Dense/Sparse 双索引，实现语义召回与关键词召回结合的混合检索。
5. 在稀疏检索侧通过 DAAT 倒排检索策略及 BM25 k1/b 参数优化查询性能与召回效果；在稠密检索侧调优索引参数 M=30、efConstruction=64，平衡检索精度与响应性能。
6. 基于 LangGraph 设计动态工作流，根据用户问题语义和上下文，将请求路由至不同知识库或外部检索源，提升复杂场景下的问题处理能力。
7. 引入 Corrective RAG 与 Adaptive RAG 构建双层评估机制，对召回文档相关性和答案生成前的输入-证据关联性进行校验，不达标时触发 Query 改写和重新检索，降低幻觉率。
8. 基于 RAGAS 建立评测闭环，持续优化召回质量与回答效果，提升系统在安防垂直场景下的实际可用性。
