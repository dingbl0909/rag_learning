# 设备接入与离线排查

## 摄像头接入基础流程

安防设备接入平台前，应先确认设备编码、组织树位置、网络地址、鉴权方式和时间同步配置是否完整。接入失败时，不要直接判断为平台故障，通常应先核对设备侧参数与平台录入信息是否一致。

## 摄像头离线排查

当摄像头在平台中显示离线时，建议按以下顺序处理：先检查交换机端口与 PoE 供电是否正常，再检查摄像头 IP 是否冲突，然后验证平台与设备之间的网络连通性，最后确认设备时间是否与平台时间一致。若日志中出现鉴权失败，应优先检查账号密码和设备序列号绑定关系。

## 人脸设备接入失败

人脸识别设备接入失败时，常见原因包括设备固件版本过低、平台协议适配未开启、设备上送图片过大或抓拍策略配置错误。建议先比对设备版本与平台支持矩阵，再检查抓拍上传开关和图片压缩参数。

## 现场实施建议

实施阶段应保留设备清单、IP 规划表、端口映射表和设备截图。这样在出现离线、重复注册或通道异常时，可以快速将问题定位到设备配置、网络环境或平台接入层。
