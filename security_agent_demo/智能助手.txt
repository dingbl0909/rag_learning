项目名称：面向安防场景的私有化大模型平台与多Agent智能助手

项目背景：
在依图从事大模型应用开发期间，负责搭建一套面向安防业务场景的私有化大模型应用平台。传统知识库问答只能覆盖静态FAQ，难以支撑运维排障、设备巡检、告警处置、前场操作指引等多步骤业务场景。为提升一线运维人员和前场实操人员的处理效率，我基于 LangChain + LangGraph 设计并落地了多Agent协同工作流，并完成模型接入、知识增强、工具治理、权限风控和私有化部署方案建设，使系统能够围绕安防设备、告警事件、工单流程和现场作业规范完成多轮问答、任务拆解、工具调用与流程执行。

项目描述：
该项目面向安防行业中的运维支持与现场作业场景，围绕设备管理、监控告警、事件处置、巡检作业、权限申请等核心流程建设私有化大模型平台能力。业务流程进一步拆分为视频流和图片流两类场景：视频流侧重实时监控、告警追踪、录像检索、事件回溯与处置建议；图片流侧重抓拍分析、图像取证、异常画面研判、现场图片问答与操作指引。平台底层支持统一模型接入、提示词编排、RAG知识增强、工具调用、会话管理和权限审计；上层通过大模型驱动的多Agent协作机制，在对话中理解用户意图，自主选择业务流程，并调用后端工具完成设备信息查询、告警定位、知识检索、工单流转、处置建议生成、标准作业指引下发等操作，为运维人员和前场实操人员提供统一的智能问答与辅助决策入口。

项目实现：
1. 工具函数模块：
将存量业务能力抽象为 LangChain Tools，统一封装为大模型可调用的工具接口，并按业务域拆分为设备查询、告警分析、知识库检索、工单处理、权限申请、现场操作指引等多个工具集。其中针对视频流场景封装录像检索、告警时间轴查询、摄像头状态分析、事件片段定位等工具；针对图片流场景封装抓拍记录查询、图片信息检索、异常图片分析结果查询、现场图片辅助问答等工具。结合操作风险对工具进行分层治理，划分为只读工具与敏感操作工具，使模型既能完成实时查询、诊断建议生成，也能在受控条件下触发工单流转、状态变更、权限审批等动作。

2. 身份信息与权限控制模块：
在主工作流入口设计用户信息拉取节点，基于请求参数获取用户ID、岗位角色和权限信息，并写入 State，确保后续所有Agent共享统一用户上下文。在敏感工具执行前增加 interrupt_before 中断机制，并结合 MemorySaver 持久化上下文状态，在人工确认、线程恢复或多轮追问场景下，依然能够通过 thread_id 和用户身份保证上下文一致性与操作安全，避免越权执行高风险操作。

3. 多Agent调度模块：
以主Agent作为统一调度中心，将复杂业务流程拆分为设备运维Agent、告警处置Agent、知识问答Agent、现场作业Agent，以及面向视频流/图片流场景的专项处理节点。主Agent负责意图识别、任务分发和跨业务切换；子Agent负责完成本领域内的查询、诊断、工具调用和结果返回。当用户问题涉及实时监控、录像回溯、视频告警时优先路由至视频流相关工作流；当问题涉及抓拍记录、图像分析、现场图片核验时优先路由至图片流相关工作流。各子工作流统一采用入口节点、决策节点、只读工具节点、敏感工具节点、退出节点的结构，通过 add_conditional_edges 实现动态路由，通过对话状态栈管理主子流程切换，提升复杂任务编排的可维护性和扩展性。

4. 状态管理模块：
基于 LangGraph State 设计统一状态结构，集中维护消息历史、用户信息、权限信息和对话状态栈。通过消息列表保存多轮上下文，通过 user_info 保证个性化业务处理，通过 dialog_stack 跟踪当前所处的业务子流程，并支持任务完成后返回主Agent继续承接后续需求，从而实现跨业务、多任务场景下的连续对话体验。

5. 平台化落地模块：
围绕私有化部署场景，设计统一的大模型接入层与应用编排层，支持基础模型替换、Prompt 模板管理、RAG 检索增强、Agent 工作流编排、工具注册、调用审计和权限隔离。结合安防行业对数据安全与内网部署的要求，优先采用私有化开源模型方案，适配本地向量库、内部知识库和业务系统接口，满足企业级可控、可追溯、可扩展的落地需求。同时针对视频流与图片流两类场景设计差异化处理链路，分别对接视频检索/告警系统和图像分析/抓拍系统，形成统一入口、分流处理、结果汇总的平台能力。

个人职责：
1. 负责整体私有化大模型平台方案设计与核心代码实现，完成基础模型接入、RAG增强、Agent 编排和会话管理等核心能力建设。
2. 负责多Agent工作流架构设计与核心代码实现，完成主Agent与多个子Agent的路由编排。
3. 负责业务工具抽象与标准化封装，打通大模型与设备管理、告警中心、知识库、工单系统等后端服务能力。
4. 负责敏感操作风控链路设计，构建用户身份注入、操作中断确认、上下文恢复等机制。
5. 负责状态管理方案设计，解决多轮对话、任务切换、主子流程回退等复杂交互问题。

项目亮点：
1. 从传统问答升级为“对话理解 + 任务拆解 + 工具执行”的智能服务闭环，提升复杂业务场景下的大模型可用性。
2. 通过主Agent + 子Agent 协同模式，降低单一Agent提示词和决策链路复杂度，提升系统可维护性。
3. 通过只读/敏感工具分层和中断确认机制，提高高风险业务操作的安全性与可控性。
4. 通过状态栈与上下文持久化机制，支持多轮对话中的任务切换、恢复与连续执行。
5. 形成可复用的大模型平台底座，可在不同安防业务场景中快速接入新知识库、新工具和新Agent能力。
6. 支持视频流与图片流双场景业务分流，能够针对不同数据形态选择合适的工作流与工具链路，提升实际落地效果。

简历精简版表述：
在依图负责安防场景私有化大模型平台落地，基于 LangChain + LangGraph 搭建主Agent + 设备运维/告警处置/知识问答/现场作业子Agent协同工作流，支持多轮对话中的任务拆解、动态路由、RAG增强与工具调用。结合视频流与图片流两类业务场景，分别对接监控告警、录像检索、抓拍分析和知识库系统，将后端能力抽象为可控工具体系，设计用户身份注入、敏感操作中断确认、Memory 持久化和状态栈管理机制，为运维人员和前场实操人员提供智能问答、故障定位和流程辅助能力。

私有化模型选型建议：
1. 商业化大规模版本：
建议优先选择 70B 级别指令模型作为平台主模型，例如 Qwen2-72B-Instruct 或 Llama3-70B-Instruct 这一量级的开源模型。该版本更适合承担复杂问答、长上下文推理、多工具调用和多Agent调度中心等核心任务，适用于安防企业级知识问答、跨系统运维分析、复杂告警归因和流程决策场景。优势在于理解与生成质量更稳定、对复杂指令和长链路任务支持更好，适合作为商业场景主模型部署。

2. 实战轻量版本：
建议选择 7B~8B 级别指令模型作为实战版本，例如 Qwen2-7B-Instruct 或 Llama3-8B-Instruct。该版本更适合你后续做原型验证、单机场景部署、RAG问答、标准流程问答和轻量Agent工具调用，能够在成本、部署复杂度和效果之间取得较好平衡。如果当前目标是快速做一个可跑通的安防运维问答系统，8B左右模型已经足够支撑知识问答、工单辅助和标准操作指引类场景。

模型落地建议：
如果是对外或对内正式商业场景，推荐采用“大模型主模型 + RAG + 重排序 + 工具调用”的组合方案，其中 70B 级别模型负责核心推理与复杂任务编排；如果是你接下来要快速实战，建议先以 8B 左右模型作为主模型，配合高质量知识库切分、向量检索和少量工具调用，先把效果跑通，再按业务复杂度逐步升级到更大参数规模。
